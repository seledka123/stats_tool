# Техническое задание
**Проект:** stats-tool — консольная программа статистической обработки числовой выборки
**Версия документа:** 1.0

## 1. Назначение
Вычисление среднего арифметического, медианы и моды числовой выборки, переданной пользователем; хранение результатов в виде дампов с возможностью резервного копирования и восстановления.

## 2. Область применения
Учебные и прикладные расчёты на рабочей станции пользователя без сетевого взаимодействия.

## 3. Функциональные требования
| ID | Требование |
|---|---|
| FR-1 | Программа вычисляет среднее арифметическое выборки. |
| FR-2 | Программа вычисляет медиану (при чётном n — среднее двух центральных значений). |
| FR-3 | Программа вычисляет моду; при нескольких модальных значениях выводит все; если все значения уникальны и n > 1, сообщает об отсутствии моды. |
| FR-4 | Ввод выборки: аргументы командной строки, интерактивный ввод/stdin, текстовый файл (`--input`). |
| FR-5 | Вывод результата: консоль или файл (`--output`), форматы `text` и `json`. |
| FR-6 | Разделители чисел: пробел, перевод строки, `,`, `;`; десятичный разделитель — `.`. |
| FR-7 | Некорректный ввод (пустая выборка, нечисловое значение, `nan`, `inf`) отклоняется с понятным сообщением и кодом возврата 1. |
| FR-8 | Результат можно сохранить как дамп (JSON) ключом `--save-dump`. |
| FR-9 | Резервное копирование дампов в ZIP-архив с манифестом и контрольными суммами SHA-256. |
| FR-10 | Восстановление дампов из архива (по умолчанию — последнего) с предварительной проверкой целостности. |
| FR-11 | Ротация резервных копий: хранятся последние N (по умолчанию 5). |
| FR-12 | Документация: README на русском и английском языках, ТЗ, регламент ТО. |

## 4. Нефункциональные требования
| ID | Требование |
|---|---|
| NFR-1 | Python 3.9+, только стандартная библиотека. |
| NFR-2 | Кроссплатформенность (Windows, Linux, macOS); кодировка файлов UTF-8. |
| NFR-3 | Выборка до 10⁶ значений обрабатывается за приемлемое время (единицы секунд). |
| NFR-4 | Запись архива атомарна: при сбое не остаётся неполных копий. |
| NFR-5 | Восстановление не должно приводить к потере текущих данных (страховая копия `.pre_restore`). |
| NFR-6 | Защита от небезопасных имён файлов в архиве (path traversal). |

## 5. Интерфейс
Команды: `calc`, `backup`, `restore`, `list`. Коды возврата: 0 — успех; 1 — ошибка данных; 2 — ошибка аргументов; 3 — ошибка файла/копии.

## 6. Алгоритм резервного копирования и восстановления
**Копирование:** сбор `dump_*.json` → SHA-256 каждого файла → `manifest.json` → запись ZIP во временный файл → атомарное переименование в `backup_<UTC>.zip` → удаление копий сверх лимита.
**Восстановление:** проверка архива (манифест, список файлов, безопасность имён, SHA-256, отсутствие лишних файлов) → распаковка во временный каталог → текущий каталог дампов переименовывается в `<имя>.pre_restore` → временный каталог становится рабочим; при ошибке — откат.

## 7. Формат дампа
```json
{"created_at": "ISO-8601 UTC", "data": [..], "count": 0, "mean": 0.0, "median": 0.0, "mode": []}
```
