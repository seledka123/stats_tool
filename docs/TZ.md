# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку консольного приложения «Статистика числовой выборки» (stats-tool)

**Проект:** stats-tool — консольное приложение для нахождения медианы, среднего арифметического и моды числовой выборки
**Версия документа:** 1.0

---

## ЧАСТЬ 1. ТРЕБОВАНИЯ ЗАКАЗЧИКА

### 1. Цель
Создать простую и надёжную программу, которая поможет студентам, школьникам и всем, кто работает с данными, быстро и без ошибок находить медиану, среднее арифметическое и моду числовой выборки, а также сохранять результаты и не терять их при сбоях.

### 2. Область применения
Программа предназначена для использования в учебном процессе (занятия по информатике, статистике, лабораторные и практические работы), а также для личных расчётов и обработки небольших наборов данных на рабочей станции без подключения к сети.

### 3. Определения, термины, сокращения

| Термин | Определение |
|---|---|
| ПО | Программное обеспечение. |
| ТЗ | Техническое задание. |
| Выборка | Набор числовых значений, переданный пользователем для обработки. |
| Среднее арифметическое | Сумма всех значений выборки, делённая на их количество. |
| Медиана | Центральное значение упорядоченной выборки; при чётном количестве значений — среднее двух центральных. |
| Мода | Значение, которое встречается в выборке чаще всего. Модальных значений может быть несколько. |
| Дамп | Файл формата JSON, в котором сохранены исходная выборка и результаты её обработки. |
| Резервная копия | ZIP-архив с дампами и манифестом, созданный программой для защиты данных от потери. |
| Манифест | Файл `manifest.json` внутри архива со списком дампов и их контрольными суммами. |
| SHA-256 | Алгоритм вычисления контрольной суммы, по которой проверяется целостность файлов. |
| Код возврата | Число, с которым программа завершается: 0 — успех, другое значение — тип ошибки. |

### 4. Краткое описание
Программа должна получать от пользователя числовую выборку (через консоль или из файла) и выдавать три показателя: среднее арифметическое, медиану и моду. Результат можно вывести на экран или записать в файл. Если все значения выборки различны, программа должна сообщить, что моды нет. Программа должна уметь сохранять результат в виде дампа, делать резервную копию дампов и восстанавливать их из копии с проверкой целостности. К программе прилагается документация: техническое задание, руководство пользователя на русском и английском языках (README.md) и регламент технического обслуживания.

## ЧАСТЬ 2. ТРЕБОВАНИЯ РАЗРАБОТЧИКА

### 1. Обзор ПС (программной системы)

| Вид интерфейса | Описание |
|---|---|
| Пользовательский интерфейс | Консольный (текстовый) интерфейс. Команды: `calc` (расчёт), `backup` (резервная копия), `restore` (восстановление), `list` (список копий). Числа можно передать аргументами, ввести по запросу в консоли или подать через стандартный ввод. |
| Аппаратный интерфейс | Стандартные устройства ввода-вывода (клавиатура, монитор). Ограничений по памяти нет, требуется любой ПК с установленным Python. |
| Программный интерфейс | Взаимодействие с файловой системой: чтение входных файлов .txt, запись результатов в .txt и .json, создание дампов (.json) и резервных копий (.zip). Используется только стандартная библиотека Python. |

### 2. Функциональное описание

| ID | Функция | Описание |
|---|---|---|
| Ф-1 | Ввод выборки вручную | Ввод чисел через консоль: аргументами команды, по запросу программы или через стандартный ввод. Разделители: пробел, перевод строки, `,` и `;`; десятичный разделитель — точка. |
| Ф-2 | Чтение выборки из файла | Чтение чисел из текстового файла в кодировке UTF-8 (параметр `-i`). |
| Ф-3 | Вычисление показателей | Вычисление среднего арифметического, медианы и моды. При нескольких модальных значениях выводятся все; если все значения уникальны и их больше одного, мода считается отсутствующей. |
| Ф-4 | Вывод результата | Вывод результата на экран или запись в файл (параметр `-o`) в текстовом формате или в формате JSON (параметр `-f`). |
| Ф-5 | Сохранение дампа | Сохранение выборки и результатов в файл `dump_<дата_время>.json` (параметр `--save-dump`). |
| Ф-6 | Резервное копирование | Создание ZIP-архива дампов с манифестом и контрольными суммами SHA-256. Архив записывается через временный файл и атомарно переименовывается. Хранятся последние N копий (по умолчанию 5). |
| Ф-7 | Восстановление | Восстановление дампов из резервной копии (по умолчанию из последней или из указанной параметром `--archive`). Перед заменой данных архив проверяется; текущие дампы сохраняются в страховую копию `dumps.pre_restore`. |
| Ф-8 | Просмотр резервных копий | Вывод списка имеющихся резервных копий. |
| Ф-9 | Обработка исключений | Обработка исключительных ситуаций: пустая выборка, нечисловое значение, значения `nan` и `inf`, отсутствующий файл, повреждённый архив, отсутствие дампов или копий. Программа сообщает об ошибке понятным сообщением и завершается с соответствующим кодом возврата, без аварийного вывода трассировки. |

### 3. Характеристики пользователя
Пользователь должен обладать базовыми навыками работы с компьютером (уметь открыть командную строку, запустить программу и ввести числа с клавиатуры). Знание языков программирования не требуется.

### 4. Ограничения

| № | Ограничение |
|---|---|
| 1 | Программа работает в операционных системах семейства Windows / Linux / macOS. |
| 2 | Для работы необходим установленный интерпретатор Python версии 3.9 или выше. |
| 3 | Программа не имеет графического интерфейса (только текст в консоли). |
| 4 | Выборка не может быть пустой; значения `nan` и `inf` не допускаются. |
| 5 | Все файлы читаются и записываются в кодировке UTF-8. |

### 5. Допущения и зависимости

| № | Допущение / зависимость |
|---|---|
| 1 | Предполагается, что пользователь вводит числа в допустимом формате (десятичный разделитель — точка). |
| 2 | Для работы резервного копирования должны существовать дампы в каталоге `data/dumps` (или в каталоге, указанном параметром `--dump-dir`). |
| 3 | Пользователь имеет права на чтение и запись в каталоге `data` и в каталоге с входными и выходными файлами. |
| 4 | Сторонние библиотеки не требуются: используется только стандартная библиотека Python. |

### 6. Файлы данных

| Файл / каталог | Назначение | Связанные функции |
|---|---|---|
| Входной файл `.txt` (путь задаёт пользователь) | Входная выборка | Ф-2 |
| Выходной файл `.txt` или `.json` (путь задаёт пользователь) | Результат расчёта | Ф-4 |
| `data/dumps/dump_<дата_время>.json` | Дампы: выборка и результаты | Ф-5, Ф-6, Ф-7 |
| `data/backups/backup_<дата_время>.zip` | Резервные копии дампов вместе с `manifest.json` | Ф-6, Ф-7, Ф-8 |
| `data/dumps.pre_restore` | Страховая копия дампов, создаваемая перед восстановлением | Ф-7 |

### 7. Коды возврата

| Код | Значение |
|---|---|
| 0 | Успешное выполнение. |
| 1 | Ошибка данных (пустая выборка, не число, недопустимое значение). |
| 2 | Неверные аргументы командной строки. |
| 3 | Ошибка работы с файлом или резервной копией. |

### 8. Порядок приёмки
Приёмка выполняется по набору из 30 тест-кейсов (см. `TEST_CASES.md`) и автоматизированным модульным тестам (`python -m unittest discover -s tests -t . -v`). Программа считается принятой, если все тест-кейсы имеют статус Passed и все модульные тесты завершаются успешно.
