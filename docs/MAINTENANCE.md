# Регламент технического обслуживания
**Объект:** stats-tool · **Версия:** 1.0

## 1. Цель
Обеспечить сохранность статистических данных и работоспособность программы в течение всего срока эксплуатации.

## 2. Ответственные
Администратор (обслуживание, резервные копии) и разработчик (исправления, релизы).

## 3. Плановые работы
| Периодичность | Работа | Команда / действие |
|---|---|---|
| Ежедневно / после серии расчётов | Резервная копия дампов | `python -m stats_tool backup` |
| Еженедельно | Проверка списка копий и свободного места | `python -m stats_tool list`; размер `data/backups` |
| Ежемесячно | Контрольное восстановление в тестовый каталог | `python -m stats_tool restore --dump-dir /tmp/check --backup-dir data/backups` |
| Ежемесячно | Прогон автотестов | `python -m unittest discover -s tests -t . -v` |
| Ежеквартально | Проверка версии Python и совместимости | `python --version` |
| Ежегодно | Пересмотр документации и лимита хранения копий (`--keep`) | — |

Автоматизация (пример cron): `0 2 * * * cd /opt/stats-tool && python -m stats_tool backup --keep 14`.
Windows: задача в «Планировщике заданий» с той же командой.

## 4. Восстановление после сбоя
1. Остановить работу с программой.
2. `python -m stats_tool list` — выбрать копию.
3. `python -m stats_tool restore --archive data/backups/backup_<...>.zip`.
4. Убедиться, что дампы в `data/dumps` на месте; прежние данные доступны в `data/dumps.pre_restore`.
5. При сообщении о несовпадении контрольной суммы взять предыдущую копию и зафиксировать инцидент.

## 5. Обновление версии
1. `git pull`, просмотр CHANGELOG/коммитов.
2. Прогон автотестов — все должны пройти.
3. Резервная копия дампов перед обновлением.
4. Контрольный расчёт: `python -m stats_tool calc 1 2 2 3`.
В случае сбоя — откат: `git checkout <предыдущий-тег>`.

## 7. Типовые неисправности
| Симптом | Причина | Действие |
|---|---|---|
| Код 1 | Нечисловое значение в выборке | Исправить входные данные; помнить: десятичный разделитель — точка |
| Код 3, «Нет дампов» | Каталог дампов пуст | Проверить `--dump-dir`, выполнить `calc --save-dump` |
| Код 3, «Контрольная сумма не совпала» | Архив повреждён | Использовать предыдущую копию |
| Код 3, ошибка доступа | Нет прав на каталог `data/` | Проверить права доступа |
