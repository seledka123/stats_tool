# Тест-кейсы

Объект проверки: консольная программа `stats-tool` (среднее арифметическое, медиана, мода; резервное копирование и восстановление дампов). Требования FR/NFR указаны в [ТЗ](TZ.md).

Тест-кейсы выполняются вручную из командной строки. Дополнительно модульные тесты запускаются командой `python -m unittest discover -s tests -t . -v` (21 тест, результат: OK). Статусы: **Passed** — пройден, **Failed** — провален, **Blocked** — заблокирован.

Кейсы №18–26 и №30 зависят друг от друга по данным (дамп → копия → восстановление), поэтому выполнять их нужно по порядку, начиная с чистой папки.
