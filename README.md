# stats-tool

🇷🇺 Русский | [🇬🇧 English](README.en.md)

Консольная программа на Python для вычисления **среднего арифметического, медианы и моды** числовой выборки с вводом/выводом через консоль или файл, а также с резервным копированием и восстановлением дампов статистических данных.

Зависимости: только стандартная библиотека, **Python 3.9+**.

## Установка

```bash
git clone https://github.com/<seledka123>/stats-tool.git
cd stats-tool
```

## Использование

### Расчёт

```bash
# из аргументов
python -m stats_tool calc 3 1 4 1 5 9 2 6 5 3 5

# интерактивно (запрос в консоли) или через stdin
python -m stats_tool calc
echo "1 2 2 3" | python -m stats_tool calc

# из файла в файл, формат JSON
python -m stats_tool calc -i sample.txt -o result.json -f json

# сохранить результат как дамп
python -m stats_tool calc -i sample.txt --save-dump
```

Формат выборки: числа через пробел, перевод строки, `,` или `;`. Десятичный разделитель — точка (`2.5`).

Пример вывода:

```
Количество / Count: 11
Среднее арифметическое / Mean: 4
Медиана / Median: 4
Мода / Mode: 5
```

Правила: при чётном числе элементов медиана — среднее двух центральных; мод может быть несколько (выводятся все); если все значения уникальны (и их больше одного), мода «отсутствует».

### Резервное копирование и восстановление

```bash
python -m stats_tool backup [--keep 5]            # создать копию дампов
python -m stats_tool list                         # список копий
python -m stats_tool restore [--archive FILE]     # восстановить (по умолчанию — последнюю)
```

По умолчанию дампы лежат в `data/dumps`, копии — в `data/backups` (меняется ключами `--dump-dir`, `--backup-dir`). Перед восстановлением архив проверяется по SHA-256; текущие дампы сохраняются в `data/dumps.pre_restore`.

### Коды возврата

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | ошибка данных (пустая выборка, не число) |
| 2 | неверные аргументы командной строки |
| 3 | ошибка файла / резервной копии |
